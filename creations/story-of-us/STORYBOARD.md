# 将故事写成我们 · claw'd

一条从空白故事册里伸出的红线，将两个小方块的生活慢慢缝成一个家。

## 画面与角色

- 1080 × 1440，3:4 竖版，完整使用用户提供视频中的 283.4 秒音频。
- 主角严格复用模板 `src/clawd.js`：陶土橙矩形身体、四条短腿、短臂、竖条眼；通过原生表情和 key views 表演。原角色代码保持一致。
- 同伴采用相同轮廓，淡玫瑰色、花饰；不用人形身体、长胳膊或服装掩盖轮廓。
- 场景是纸上的旧街、茶桌、小屋、花园、河边与车站。水彩色块和抖动墨线，冷灰蓝逐渐转为暖杏色。
- 每镜读点依次是“注意到 → 行动 → 对方回应 → 留白”。人物脚底大多落在 y=990，歌词区 y=1240–1350。
- 字幕来自用户提供的视频，OCR 确认实际高亮行切换。网上歌词只做信息检索；不照搬其他版本的时间轴。

## 故事结构

| 乐段 | 画面事件与读点 | 转场和回收 |
|---|---|---|
| 初遇 | claw'd 翻开空白册，纸页飘成小街；两人各自绕路，终于在路灯下撞见。先看孤单，再看对方，再看害羞。 | 翻页；两人的红线在中间打一个结。 |
| 惦念 | 窗边的一朵花被放进册页；两份回忆小画被并排收藏。 | 花瓣匹配为茶杯蒸汽。 |
| 热茶 | 主角把杯子推过去，同伴把自己的杯子也移近；主角指向小屋，同伴在窗边摆好花。 | 两缕蒸汽合成心形；屋顶扫过镜头。 |
| 第一遍副歌 | 一个主角画在册页上；同伴走进另一页，两只短臂一起执笔；红线把页缝合。两人从欲转身到重新靠近，轻轻碰脸。 | 册页与生活交替，红线贯穿。 |
| 未来 | 两人并肩坐等日出；一起种下小树、撑伞护苗；花开，两人走进亮着灯的门。 | 种子、树与屋成为后文固定道具。 |
| 第二遍主歌 | 熟悉的小街里再次相遇，这次主动等对方；雨中让伞、回忆册加页、茶桌上两只杯。 | 第一遍构图重现，关系更亲密。 |
| 第二遍副歌 | 一起修好小屋；风雪里披同一条围巾；收进行李的不是贵重东西，而是花、杯子和故事册。站台告别城市，两人同向出发。 | 红线变为铁轨，画面随车窗推移。 |
| 愿意 | 主角紧张拿出戒指，同伴先伸手；对视，点头，再牵手走进家。 | 戒指圆形匹配为灯罩，灯亮。 |
| 桥段 | 双手特写后拉开到河边步道；四季从两人身后经过。他们停下相望，在家门前拥近。 | 镜头由近到远再近，花瓣遮镜。 |
| 最后一遍副歌 | 回忆册已很厚，过去的小街、雨伞和车站以相同构图重现；两人一起收拾行李，但也一起回家。 | 红线持续连着彼此，复现镜头动作升级。 |
| 结尾 | 年长的两人坐在树下翻册；窗内灯亮。末页同时画着两个 claw'd，册子慢慢合上，红线结成心。 | 呼应最初孤单的一页；缓慢收束，留足尾音。 |

详细切点在 `src/scenes/story.js`；字幕时间和采样证据分别在 `reference/lyrics-timed.json` 和 `reference/ocr.json`。时间轴以本地参考文件为准。

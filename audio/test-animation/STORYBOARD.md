# 慢慢喜欢你 · 动画分镜

**Logline:** 两个原本各自赶路的小伙伴，从一次替对方护住小花开始，用许多不起眼的照料慢慢走到一起；多年后，他们仍在最初相遇的雨棚下并肩回家。

**World:** 一座临海小城，水彩和晕染墨线。开场是冷青灰的雨，经过咖啡馆与家中的陶土、蜂蜜暖色，到冬日靛蓝，再由嫩绿春光过渡到暖金晨光。所有场景属于同一座城市与同一套小公寓。

**Motif:** 一朵小黄花。初遇时被雨淋弯，后来插在咖啡杯里、种进窗台小盆、长成家中的花；结尾同一朵花在两人之间摇曳。

**Cast:**
- **陶土色小伙伴 A：** 起初谨慎、习惯独自解决事情；通过照料和被照料逐渐放松，最后自然地伸出手。
- **玫瑰色小伙伴 B：** 戴一朵小花，温柔而有主意；先给出小小的帮助，也愿意接纳 A 的回应。

**动作与节拍：** 约 130.8 BPM 的检测结果按半拍 65.4 BPM 用于轻柔摆动和重动作；首个检测拍约在 0.39 s。没有歌词文件，因此不制作歌词字幕，视觉只表演生活里的细节。

| 章节 / 时间 | 场景与动作 | 情绪和转场 |
|---|---|---|
| 01 · 0–27.5s | 雨棚初遇。A 看见被雨打弯的小花，笨拙地把伞移过去；B 抬头发现 A 鞋边漏进的水，反过来替 A 挪开积水。两人一起护住花。 | 冷青灰 → 微暖；花瓣擦镜开场，伞面形状接下一章。 |
| 02 · 27.5–55s | 咖啡馆初约。A 拉椅子、推来一杯热饮；B 看出 A 的杯子太烫，垫上纸套。打翻的糖粒被两人一颗颗收好，最后对视发笑。 | 雨声变窗上水痕；杯中蒸汽溶成下一章的云。 |
| 03 · 55–82.5s | 回家路上共伞。两人轮流把伞倾向对方；走到水洼前停步，互相让路后一起跨过去，肩头轻轻碰上。 | 伞沿横扫；水洼倒影成为厨房窗。 |
| 04 · 82.5–110s | 一起做饭。A 烤焦一片吐司，慌忙藏起；B 发现后没取笑，只煎蛋盖住焦边。两人分食最后一口，并把黄花放进杯子。 | 热气作柔和遮幅；窗外转成冬色。 |
| 05 · 110–137.5s | 冬日照料。B 感冒蜷在沙发，A 递水、加毯子、守着药汤；之后 A 因忙碌睡着，B 把围巾盖回 A 肩上。 | 蓝灰窗光里一点暖灯；毯子铺满画面转到春天。 |
| 06 · 137.5–165s | 窗台种花。两人把小花移进土盆，轮流浇水；日影变化、叶片抽芽、花苞打开。换大盆时泥土洒落，两人笑着一起清理。 | 颜色由嫩绿转暖；花朵的圆形匹配成厨房餐盘。 |
| 07 · 165–192.5s | 家中寻常日子。洗衣、叠衣、修伞、晾花；两人各做各的却总替对方留一盏灯、递一把椅子。旧伞修好后，两人靠着窗边小憩。 | 柔和傍晚光；窗外雨线把画面带回初遇的雨棚。 |
| 08 · 192.5–220.22s | 回到同一雨棚。两人站回开场的位置，但这次共撑一把旧伞；A 把伞柄递给 B，两只手自然叠在一起。小黄花在伞边摇动，雨停，二人并肩离开。 | 同构开场构图但更暖；花瓣形 iris 慢慢收束。 |

**每章镜头节点：** 每章约 27.5 秒，内部以约 6.8 秒为镜头节奏。镜头动作是连续的：注意到细节 → 做出小动作 → 对方回应 → 留一拍给情绪落下。每个章节边界用画面里的物件/色彩擦拭，避免硬切。

**收尾回环：** 开场 A 独自在雨棚护花，结尾两人共伞护花；同一雨线、同一站位、同一朵花，关系已经改变。
